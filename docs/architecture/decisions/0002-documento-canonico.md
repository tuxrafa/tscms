# Documento canônico

Páginas, templates e fragmentos persistem o schema `schemaVersion: 1`. Há slots, seções, conteúdo padrão, blocos e referências de fragmento.

Auto-blocking devolve uma cópia. Não altera o documento guardado. Se uma composição não cabe no contrato EDS, o adaptador rejeita em vez de inventar wrappers.
