# Sites independentes

Cada website tem Git, CSS, fontes e JavaScript de bloco próprios. O CMS registra o site, os domínios e o manifesto publicado. Não clona o repositório do site para publicar conteúdo.

`tscms upgrade` sem `--dry-run` termina com erro e não escreve arquivo. O plano seco lista CSS, blocos e `scripts.js` como preservados.
