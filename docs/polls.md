# Enquetes

A votação pública não exige login. A versão atual permite votos repetidos e não garante uma pessoa por voto. Limite em memória reduz abuso simples. CAPTCHA, cookie e antifraude são políticas futuras, desligadas.

Resultados seguem a política da enquete: sempre, depois do voto, depois do encerramento ou ocultos. A API não devolve resultado oculto. O bloco aponta para o mesmo poll id em qualquer página.
