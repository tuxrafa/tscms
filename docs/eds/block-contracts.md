# Contratos de bloco

Hero: primeira linha com imagem, segunda com título, texto e links. A variante `centered` é classe.

Cards: uma linha por item. A célula com `picture` vira a imagem; a outra, o corpo. O JavaScript do site transforma as linhas em lista.

Columns: uma linha com uma célula por coluna.

Accordion e FAQ: título na primeira célula e corpo na segunda. FAQ usa a classe `faq`, não aninha um bloco accordion.

Fragmentos editoriais são resolvidos antes do HTML quando `fragments.delivery` é `resolve`. O modo `eds-block` deixa a referência para o bloco `fragment` do site.
