# Templates

Os modelos iniciais são home, landing, lista do blog, artigo, institucional, contato e preços. Eles definem slots e políticas: locked, editable, configurable, initial e shared.

A página guarda `templateId` e o conteúdo dos slots editáveis. O template inteiro não é copiado para cada página. Publicar uma página com template exige a revisão publicada do template.
