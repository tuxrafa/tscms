# Canvas

O canvas edita o documento canônico. Arrastar um item da biblioteca ou clicar nele insere um nó. Desfazer e refazer usam o histórico do schema. O inspetor edita campos simples.

A pré-visualização abre o HTML da Delivery API em outra aba. O overlay de seleção do renderer fica fora do `main` e fala com o Author por `postMessage`. O CSS dessa página é o do site, não o do estúdio.
