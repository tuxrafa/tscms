# Catálogo

O catálogo em `packages/block-registry` tem os 56 componentes editoriais mais os globais: header, navegação, footer, aviso, busca, 404, consentimento e região de fragmento.

Cada item tem nome, campos, exemplo, variante e estado de compatibilidade. O site é dono do CSS. O pacote de referência só descreve dados e o adapter HTML neutro.

Componentes globais são configuração do CMS. O header de um cliente não fica no núcleo.
